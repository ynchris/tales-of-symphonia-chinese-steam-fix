# 仙乐传说 Steam 汉化兼容补丁

基于 3DM 轩辕汉化组 v2.0 汉化补丁制作，修复新版游戏使用汉化缺少MSAA和Anisotropic filtering，以及4K分辨率不正常生效的问题。

## 使用

1. 在 [下载页面](https://github.com/ynchris/tales-of-symphonia-chinese-steam-fix/releases/latest) 下载 `TOS-CHS-v0.5-Steam.zip`，不要下载 Source code。
2. 退出游戏，将 ZIP 内全部文件解压到 `TOS.exe` 所在目录。
3. 双击 `Install-CHS.cmd`，允许管理员权限，然后从 Steam 启动游戏。

卸载：退出游戏，双击 `Uninstall-CHS.cmd`。

请使用未打旧汉化的 Steam 版，游戏路径使用英文。安装器会备份并校验主程序，拒绝未知版本。
